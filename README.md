# The International 2026 — Tournament Platform & Fantasy Compendium

Полноценная турнирная киберспортивная платформа по Dota 2 с механикой **The International Compendium Fantasy**, прогнозами (Pick'ems) на матчи сетки, системой ростеров команд с жестко закрепленными слотами ролей и обязательной верификацией Steam.

---

## 🌟 Ключевые возможности

### 1. The International 2026 Compendium Fantasy
- **3 Золотых баннера Compendium** (как в клиенте Dota 2):
  - **ОСНОВА** (Керри — Позиция 1 и Оффлейнер — Позиция 3).
  - **ЦЕНТР** (Мидлейнер — Позиция 2).
  - **ПОДДЕРЖКА** (Частичная поддержка — Позиция 4 и Полная поддержка — Позиция 5).
- **Выбор из 4 игроков своей роли**:
  - На слот Керри можно выбрать только из 4 керри зарегистрированных команд турнира, на Мид — из 4 мидеров, и т.д.
- **Жетоны перековки (20 Reroll Tokens)**:
  - Каждый пользователь получает 20 жетонов перековки.
  - Каждая карточка имеет 3 случайных бонуса (+15%..+50% к Убийствам, GPM, CS, Вардам, Рошану, FB, Снижению штрафа за смерти и т.д.).
  - Можно тратить жетоны на перековку характеристик карточки для идеальной синергии со статистикой игрока.
- **Официальная формула подсчета очков TI**:
  - Убийства: `0.3 pts * (1 + bonusKills)`
  - Смерти: `max(0, 3.0 - (deaths * 0.3 * (1 - bonusDeaths)))`
  - Добивания (CS): `(last_hits + denies) * 0.003 * (1 + bonusCS)`
  - GPM: `gpm * 0.002 * (1 + bonusGPM)`
  - Варды: `(placed + destroyed) * 0.5 * (1 + bonusWards)`
  - Вышки: `tower_kills * 1.0 * (1 + bonusTowers)`
  - Рошан: `roshan_kills * 1.5 * (1 + bonusRoshan)`
  - First Blood: `4.0 pts * (1 + bonusFB)`
  - Ассисты: `assists * 0.15 * (1 + bonusAssists)`
  - Оглушения: `stuns * 0.05 * (1 + bonusStuns)`

### 2. Сетка турнира (4 команды, Double Elimination Bo3)
- Верхняя сетка (Upper Bracket): Полуфиналы UB1 и UB2, Финал UBF.
- Нижняя сетка (Lower Bracket): Раунд 1 LB1 (матч на вылет), Финал LBF.
- Гранд-Финал (Grand Final Bo3).
- Автоматическое продвижение победителей и падение проигравших по сетке.

### 3. Прогнозы (Pick'ems)
- Прогноз на победителя матча: **+5 очков**.
- Прогноз на точный счет серии Bo3 (2:0, 2:1, 0:2, 1:2): **+5 очков**.
- Максимум **10 очков** за каждый матч в общий зачет.

### 4. Ростеры команд с привязкой к ролям
- Капитан создает команду и выбирает свой слот роли.
- Команда получает ссылку-приглашение (`/teams/join/[inviteCode]`).
- Игрок по ссылке видит занятые слоты и свободные роли, и выбирает конкретный слот (Керри, Мид, Оффлейн, Саппорты).
- Все 5 основных игроков обязаны иметь привязанный Steam для квалификации команды на турнир.

### 5. Аутентификация и Steam OpenID 2.0
- Регистрация по логину и паролю.
- Вход через Steam OpenID 2.0 (автоматический сбор SteamID64, аватара, persona name).
- Возможность привязать Steam в личном профиле.
- Режим быстрого тест-входа (Steam Pro Mock) для локальной разработки.

### 6. Админ-панель
- Кнопка **"4 Команды TI (Демо-сид)"** для мгновенного заполнения турнира легендарными составами (Team Liquid, Gaimin Gladiators, Team Spirit, BetBoom Team).
- Кнопка **"Выложить сетку турнира"** со случайным посевом 4 команд.
- Блокировка/разблокировка фэнтези и прогнозов перед играми.
- Завершение матчей с вводом счета Bo3 и автоматической генерацией реалистичной статистики TI 2026.

## 🚀 Быстрый старт (Локально)

1. Клонируйте проект и перейдите в директорию:
```bash
cd tournament-platform
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Откройте [http://localhost:3000](http://localhost:3000). Локальная база данных (PostgreSQL на движке PGlite) запустится и инициализирует таблицы автоматически!

## ☁️ Развертывание на Vercel + Neon (Postgres)

### Шаг 1: Создание базы данных Neon
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) и создайте новый проект (например, `ti2026-esports`).
2. Скопируйте строку подключения `Connection String` (выберите `Pooled connection`). Она выглядит так:
   ```
   postgres://username:password@ep-sample-pooler.us-east-2.aws.neon.tech/neondb?sslmode=require
   ```

### Шаг 2: Получение Steam Web API Key
1. Авторизуйтесь в Steam и перейдите на страницу: [https://steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)
2. В поле `Domain Name` укажите ваш домен на Vercel (например, `my-ti2026.vercel.app` или `localhost`).
3. Скопируйте сгенерированный 32-значный ключ API.

### Шаг 3: Настройка переменных окружения на Vercel
В настройках проекта Vercel (`Project Settings` -> `Environment Variables`) добавьте:

| Переменная | Описание | Пример значения |
|---|---|---|
| `DATABASE_URL` | Строка подключения Neon Postgres | `postgres://user:pass@ep-pooler.neon.tech/neondb?sslmode=require` |
| `AUTH_SECRET` | Секретный ключ для JWT подписи | Случайная строка из 32+ символов |
| `STEAM_API_KEY` | Ключ Steam Web API | `B83F...` |
| `NEXT_PUBLIC_APP_URL` | Публичный URL вашего приложения | `https://my-ti2026.vercel.app` |

После деплоя при первом же запросе таблицы базы данных и стартовый турнир создадутся автоматически.

В проекте реализованы модульные и сквозные интеграционные тесты:

```bash

# Тесты логики сетки Double Elimination и прогнозов:
node ./dist-tests/tests/bracket.test.js

node ./dist-tests/tests/tournament_flow.test.js
```
