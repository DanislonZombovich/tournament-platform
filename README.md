# Dota 2 Tournament Platform & Fantasy League

Современная киберспортивная платформа для организации и проведения турниров по Dota 2 с интерактивной сеткой плей-офф, фэнтези-лигой по правилам The International Compendium, прогнозами на матчи (Pick'ems) и жесткой системой валидации составов команд через Steam OpenID.

Проект построен на стеке Next.js 16 (App Router), серверной PostgreSQL базе данных Neon и Tailwind CSS с кастомной киберспортивной темой в темно-синих тонах (Cyber Sapphire & Cyan).

---

## Ключевые возможности платформы

### 1. Динамическое создание и проведение турниров (`/tournaments`)
- Любой авторизованный пользователь может создать свой турнир за несколько секунд.
- Гибкие настройки формата:
  - Формат сетки: Single Elimination (олимпийская система) или Double Elimination (с нижней сеткой лузеров).
  - Количество участников: 4, 8 или 16 команд.
  - Доступ: открытый публичный турнир или приватный с защитой по паролю (access code).
  - Призовой фонд, описание, даты и баннеры.
- Каталог турниров с поиском по названию и фильтрацией по статусу: "Все", "Регистрация", "Идет турнир", "Завершен".
- Флагманский турнир The International 2026 предустановлен на платформе в качестве эталонного чемпионата.

### 2. Интерактивная турнирная сетка и управление матчами (`/` и `/lib/bracket.ts`)
- Динамическая генерация структуры матчей для 4, 8 и 16 команд под выбранный формат.
- Поддержка матчей формата Bo1 и Bo3.
- Автоматическое продвижение победителей в следующие раунды и падение проигравших команд в нижнюю сетку (в Double Elimination).
- Автоматическое определение чемпиона турнира при завершении гранд-финала.

### 3. Фэнтези-лига The International Compendium (`/fantasy` и `/lib/fantasy.ts`)
- Полное соответствие официальному формату The International: 5 индивидуальных слотов ролей (Pos 1 Керри, Pos 2 Мид, Pos 3 Оффлейн, Pos 4 Частичная поддержка, Pos 5 Полная поддержка).
- Ростер карточек формируется строго из реальных игроков команд, участвующих в выбранном турнире.
- Механика жетонов перековки (20 Reroll Tokens на турнир):
  - Каждая карточка содержит 3 случайно выпавших бонуса (+15%..+50% к ключевым показателям).
  - Пользователь может тратить жетоны на перековку характеристик для максимизации итогового счета.
- Официальная формула расчета очков Valve TI:
  - Убийства: `kills * 0.3 * (1 + bonusKills)`
  - Смерти: `max(0, 3.0 - (deaths * 0.3 * (1 - bonusDeaths)))`
  - Добивания (CS): `(last_hits + denies) * 0.003 * (1 + bonusCS)`
  - GPM: `gpm * 0.002 * (1 + bonusGPM)`
  - Варды: `(placed + destroyed) * 0.5 * (1 + bonusWards)`
  - Башни: `tower_kills * 1.0 * (1 + bonusTowers)`
  - Рошан: `roshan_kills * 1.5 * (1 + bonusRoshan)`
  - Первая кровь (First Blood): `4.0 * (1 + bonusFB)`
  - Ассисты: `assists * 0.15 * (1 + bonusAssists)`
  - Оглушения: `stuns * 0.05 * (1 + bonusStuns)`
- Таблица лидеров фэнтези с ранжированием участников в реальном времени.

### 4. Прогнозы на матчи (Pick'ems, `/predictions`)
- Прогноз на победителя серии Bo3: +5 очков.
- Прогноз на точный счет серии (2:0, 2:1, 0:2, 1:2): +5 очков.
- Итого до 10 очков за каждый матч турнира.
- Фиксация прогнозов перед началом матча для предотвращения манипуляций.

### 5. Команды и ростеры с верификацией Steam (`/teams`)
- Капитан создает команду и закрепляет за собой позицию на поле.
- Создание команды и участие в ростерах требует обязательной привязки SteamID.
- Приглашение тиммейтов по уникальной ссылке (`/teams/join/[inviteCode]`).
- Четкое распределение ролей: каждый игрок занимает конкретную позицию (1-5) или слот запасного.
- Строгий допуск к турниру: команда может зарегистрироваться только тогда, когда все 5 игроков стартового состава привязали свои аккаунты Steam.

### 6. Мульти-аутентификация и безопасность
- Вход и регистрация через Steam OpenID 2.0.
- Онбординг новых игроков через Steam с обязательным выбором никнейма на платформе (`/auth/setup-username`).
- Классическая регистрация по Email и паролю с двухфакторным подтверждением через 6-значный проверочный код.
- Привязка Steam к существующему Email-аккаунту в личном кабинете.
- Быстрый режим тест-авторизации (Steam Pro Mock) для удобной локальной разработки.

### 7. Админ-панель турнирного оператора (`/admin`)
- Быстрый посев 4 демонстрационных грандов TI (Team Liquid, Gaimin Gladiators, Team Spirit, BetBoom Team).
- Жеребьевка и генерация сетки матчей.
- Блокировка и разблокировка фэнтези и прогнозов перед игровым днем.
- Ввод результатов серии с автоматической генерацией реалистичной игровой статистики TI для расчета очков фэнтези.
- Идемпотентный пересчет очков и каскадный сброс зависимых матчей при изменении результатов.
- Полный сброс турнира в начальное состояние.

## Архитектура и технологии

| Компонент | Стек / Технология | Назначение |
|---|---|---|
| Фреймворк | Next.js 16 (React 19, TypeScript) | Server & Client Components, Route Handlers |
| Стилизация | Tailwind CSS | Кастомная палитра Cyber Sapphire & Cyan, темный режим |
| База данных | Neon Serverless PostgreSQL | Облачная масштабируемая реляционная БД (`@neondatabase/serverless`) |
| Локальная БД | @electric-sql/pglite | Легковесный in-memory/embedded Postgres для локальных тестов |
| Аутентификация | Custom Auth + Steam OpenID 2.0 | Сессии на базе безопасных JWT токенов |
| Хостинг | Vercel | Serverless деплой и Edge маршрутизация |

## Быстрый старт (Локальная разработка)

### Требования
- Node.js 20 или новее
- npm или yarn

### 1. Клонирование репозитория
```bash
git clone https://github.com/DanislonZombovich/tournament-platform.git
cd tournament-platform
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе предоставленного примера:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
DATABASE_URL="postgres://username:password@ep-sample-pooler.us-east-2.aws.neon.tech/neondb?sslmode=require"
AUTH_SECRET="your-32-character-secret-key-for-jwt-signing"
STEAM_API_KEY="your-steam-web-api-key"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

> **Примечание:** Если `DATABASE_URL` не указан, приложение автоматически запустит встроенный локальный PGlite Postgres и выполнит миграцию схемы при первом обращении.

### 4. Запуск сервера разработки
```bash
npm run dev
```

Приложение доступно по адресу [http://localhost:3000](http://localhost:3000).

## Развертывание в продакшн (Vercel + Neon)

### 1. База данных Neon
1. Зарегистрируйтесь на [neon.tech](https://neon.tech) и создайте базу данных (например, `tournament_db`).
2. Скопируйте строку подключения `Connection String` с включенным пулером соединений (`Pooled connection`):
   ```text
   postgres://username:password@ep-sample-pooler.us-east-2.aws.neon.tech/tournament_db?sslmode=require
   ```

### 2. Ключ Steam Web API
1. Получите ключ на официальной странице Valve: [https://steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey).
2. В качестве домена укажите URL вашего проекта на Vercel (например, `my-dota-platform.vercel.app`).

### 3. Переменные окружения на Vercel
В панели управления проектом Vercel (`Settings -> Environment Variables`) добавьте:

| Переменная | Описание | Обязательна |
|---|---|---|
| `DATABASE_URL` | Строка подключения к Neon Postgres | Да |
| `AUTH_SECRET` | 32-битный секретный ключ для подписи сессионных JWT | Да |
| `STEAM_API_KEY` | Ключ доступа к Steam Web API | Да (для Steam Auth) |
| `NEXT_PUBLIC_APP_URL` | Публичный HTTPS-адрес развернутого приложения | Да |

База данных инициализирует необходимые таблицы и флагманский турнир The International 2026 автоматически при первом запросе к приложению.
